# [편향-분산 트레이드오프]

## 한 줄 정의
- 편향은 모델이 반복적으로 한쪽 방향으로 빗나가는 정도를 뜻하고 분산은 학습 데이터가 조금 바뀔때 예측이 흔들리는 정도

- 이 둘은 트레이드오프 관계 즉 복잡도에 따라 상관관계가 결정되는 구조
- 복잡도가 높다는 말은 "같은 문제를 다른 훈련 데이터로 학습했을 때 모델의 예측값들이 여러 방향으로 많이 흔들린다" 말과 동일
- 그러므로 복잡도가 높으면 분산이 높고 한쪽으로 몰리는 경향이 없기에 편향은 낮다 반대로 복잡도가 낮으면 분산이 낮고 편향이 크다

## 왜 필요한가 / 어떤 문제를 해결하는가
- 복잡도를 통한 편향과 분산은 해당 모델의 표현력을 뜻하기도 함
- 예측값의 분포정도를 알아서 과적합과 과소적합이 일어났을 시 해결 방안에 대해 구체적으로 대응할 수 있음
- 우선적으로 이를 해결하기 위해서 예측값을 내기 위한 각각의 트리의 깊이를 조절하고 L2벌점을 사용하는 Ridge규제 기법과 L1벌점을 사용하는 Lasso규제 기법의 알파값을 조절함으로써 해결이 가능하고 모델 크기같은 하이퍼파라미터를 조절하면 해결이 가능함
- 예를 들어 편향이 크다면 앙상블 기법 중 부스팅 기법을 사용하여 각 모델을 지날 때마다 이전 모델에 있던 편향을 줄이는 방식을 택할수도 있고 분산이 크다면 배깅의 랜덤 포레스트 방식을 통해 여러 트리의 결과값을 평균을 내어 분산을 줄이는 방식을 택할 수도 있음

## 헷갈렸던 부분
- 처음에 편향과 분산이 무엇을 뜻하는지 정도만 알고 어떤 값을 기준으로 하는지와 이걸 해결함으로써 어떤 문제가 해소되는지에 대한 정의도 정확하게 알고있지 않았음
- 이를 해소하기 위한 방법들인 규제, 하이퍼파라미터의 수정이 있는지도 몰랐고 부스팅 기법과 랜덤포레스트가 연관되어 있는지도 몰랐다

# [편향-분산 트레이드오프]이 내부적으로 동작하는 방식

## 궁금했던 질문
- "왜 편향이 높아지면 분산이 낮아지지?" 상관관계가 무엇 때문에 생기는걸까
- 복잡도가 높다는게 뭘까? 복잡도가 왜 모델의 표현력이랑 무슨 관련이 있지?
- 과소적합이랑 과적합이 편향-분산 트레이드오프와 어떤 연관이 있을까?

## 찾아본 내용 요약
- 일단 편향이 높아지면 분산이 낮아지는 이유는 말그대로 편향은 한쪽으로 빗나가 모여있는 것이고 분산은 여러 군데로 흩어져 있는 것이기에 공존하기가 힘들다
- 복잡도가 높다는 것은 하나의 데이터로 여러 모델을 돌렸을 때 나오는 예측값들이 실제 정답 값 근처에 몰려있는 것이 아니라 여러 군데로 흩어져 있어 규칙이 많이 존재하는 것과 비슷하다고 이해하면 됨
- 위의 내용을 보충하자면 성능(정답값과 예측값의 차이가 작을수록 좋음)은 괜찮은데 복잡도가 높을 때 즉 분산이 클 때의 데이터로 학습한 모델들을 사용하면 다른 새로운 데이터, 규칙이 들어온다면 예측이 크게 흔들리며 과적합 현상이 일어남
- 반대로 복잡도가 낮을 떄 즉 편향이 클 때의 학습한 모델들을 사용하면 데이터, 규칙이 너무 단순하여 규칙을 제대로 배우지 못해서 새로운 데이터가 들어온다면 평균적으로 많이 틀릴 가능성이 있음
- 과소적합 = 편향이 큰상태, 과적합 = 분산이 큰 상태

## 그림/비유로 정리
- 총게임을 할때 스킬이 한개만 있으면 단순하여 그 기술에만 집중할 수 있지만 다른 스킬로 바뀌었을 시 헷갈리기 쉽고(과소적합) 여러개의 스킬이 있을 때 외울게 너무 많아서 다른 스킬들로 대체되었을 시에 적응이 될수도 있고 안될 수도 있는 경우에 놓이기 쉽다(과적합)

## 결론
- 예측값과 정답 사이의 차이를 하나의 데이터가 아닌 여러 개의 데이터의 분포로도 모델의 성능과 개선 방안을 알아낼 수 있음
