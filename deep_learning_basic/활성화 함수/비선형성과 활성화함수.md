# [비선형성과 활성화 함수]

## 한 줄 정의
- (기존 MLP 구조처럼 은닉층을 늘린다면 입력값을 여러 조합을 한 선형 함수일 뿐이여서
표현 능력 자체는 늘지않는데 않기에 이 함수에 대한 복잡하고 풍부한 표현을 갖게 하기 위해
비선형성을 띄는 ReLU나 Leaky ReLU와 같은 함수를 적용시킨다)
- (위와 같은 비선형성을 부여하는 활성화 함수가 있는 반면 출력층에서 확률을 표현하여
모델의 출력을 우리가 해석할 수 있는 형태로 바꾸기 위한 활성화 함수도 존재한다)

## 왜 필요한가 / 어떤 문제를 해결하는가
- 비선형성을 띄는 활성화함수를 사용하는 이유는 이를 사용하지 않으면 어떤 모델이건
선형 결정만 가능한 선형함수로만 존재할 수 있게 되며 출력층을 해석하는 것에 어려움을 겪음
- 위와 같은 문제를 해결하고자 어떻게 반응할지 결정할 수 있게 해주는 활성화 함수를 적용한 것
- 비선형 활성화함수 ReLU같은 경우는 선형함수가 음수가 되는 것을 모두 0으로 만들어
의미 있는 것인지에 대한 활성화 여부를 구분지었고꺾임을 주며 선형 변환한 것을 받아 
가중치는 기울기, x값은 꺾이는 위치, 편향은 평행이동과 같이 여러 조합을 통해 비선형 표현
- 출력층 활성화함수에서 softmax나 sigmoid같은 경우는 지수함수를 적용하여
지수함수 특성상 큰갑은 더 강하게 강조되기 때문에 점수차이를 강조하고
지수함수는 항상 양수이기에 전체합으로 나누면 모든 확률이 0~1사이가 되고 합이 1이 됨

## 찾아본 내용 요약
- 비선형 함수가 가중합되면 각각의 그래프가 이어진 형태의 모양이 구성이 됨
- CrossEntropyLoss는 각 클래스에 번호(인덱스)를 부여하고, 모델이 각 클래스에 대해 출력한 logit 점수를 사용한다. 정답 라벨의 클래스 번호를 기준으로 정답 클래스(출력값)의 점수가 다른 클래스보다 얼마나 낮은지를 반영하여(softmax함수로 관계 반영) loss를 계산한다. 이후 역전파와 Optimizer를 통해 정답 클래스의 점수는 높아지고 오답 클래스의 점수는 상대적으로 낮아지는 방향으로 가중치가 업데이트된다.
- BCEWithLogitsLoss는 각 출력값을 독립적인 0/1(이진분류) 문제로 보고, 각 출력의 logit
(지수함수를 사용하는 시그모이드 함수를 통해 0과 1사이의 값으로 만들어 1일 확률이 몇퍼센트에 가까운지 확률을 볼 수 있고 threshold를 기준으로 분류도 가능)과
 해당 정답값(0 또는 1)을 각각 비교하여 loss를 계산한다.
예측값(Sigmoid)   정답
    0.9             1
    0.2             0
    0.7             1

0.9 vs 1 → 작은 Loss
0.2 vs 0 → 큰 Loss
0.7 vs 1 → 비교적 작은 Loss

- long은 int64로 분류 판단인 이런 문제의 특성상 int32나 float로는 불가능하여 .dytpe(long)으로 값을 변환함
- 클래스도 줘야 함

## 결론
이진 분류는 두 가지 중 하나를 선택하는 문제이고, 보통 Sigmoid와 BCEWithLogitsLoss를 사용한다. Sigmoid는 하나의 logit을 0~1 사이의 값으로 바꾸고, BCE는 그 예측값과 실제 0/1 정답의 차이를 이용해 loss를 계산한다.

다중 분류는 여러 class 중 정확히 하나를 선택하는 문제이다. 이때 class들이 서로 경쟁하도록 Softmax 구조를 사용하며, CrossEntropyLoss가 정답 class에 높은 점수를 주도록 학습시킨다.

다중 레이블은 여러 class가 동시에 정답이 될 수 있는 문제이다. 각각을 독립적인 YES/NO 문제로 보기 때문에 Sigmoid와 BCEWithLogitsLoss를 사용한다.

따라서 핵심 차이는 class의 개수가 아니라, 하나의 샘플에 정답이 하나만 존재하는지 여러 개가 동시에 존재할 수 있는지이다.
