## 찾아본 내용 요약
- squeeze(0) 스퀴즈는 차원을 제거하는 역할, 0처럼 차원을 정해줘야하며 그렇지 않으면 크기가 1(차원)인 모든 차원을 제거함
- unsqueeze(0) 언스퀴즈는 위와 반대로 차원을 추가해주는 역할, 이것도 0처럼 차원을 정해줘야하며 1을 넣으면 말그대로 1차원(열)이 추가됨 차원이 맞지 않을 때 요령껏 추가
- Broadcasting은 서로 다른 shape의 Tensor를 연산할 때 파이토치가 가능한 경우 자동으로 "크기"를 맞춰주는 규칙
- 말 그대로 크기를 맞춰주는게 목적이다 보니 안에 있는 데이터의 정보가 원하는 방향대로 유지되거나 효율적이지만은 않음
- shape의 오른쪽부터 비교하여 각 차원의 수가 같거나 하나가 1일 때 적용
- 배수는 되지 않고 1만 적용되는 이유는 Broadcasting의 목적은 각 텐서가 합쳐지거나 빼짐으로써 전하고자 하는 의미를 유지하고 효율적으로 하기 위함인데 배수인 경우에 복제를 하게된다면 그 안에서 반복이 일어나기 때문에 일정하지 않음
- 이러한 경우처럼 단순 1만 가능하도록 규칙을 정했다

- 최적화의 정확한 역할은 Loss를 줄이기 위해 모델의 가중치를 어떻게 업데이트할지 손실함수를 통해 얻은 값을 가중치에 어떻게 적용시킬지를 결정하는 것
- SGD는 gradient 방향으로 정해진 학습률만큼 이동, 학습률은 거의 일정하게 적용하며 일반화 성능이 좋은 경우가 많음
- Adam은 gradient의 크기와 누적 정보를 이용하여 이동하며 파라미터마다 적응적으로 조정
